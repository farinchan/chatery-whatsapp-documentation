## 🛠 Installation

### Option 1: Standard Installation

```bash
# Clone the repository
git clone https://github.com/farinchan/chatery_whatsapp.git
cd chatery_whatsapp

# Install dependencies
npm install

# Create environment file
cp .env.example .env

# Start the server
npm start

# Or development mode with auto-reload
npm run dev
```

### Option 2: Docker Installation

```bash
# Clone the repository
git clone https://github.com/farinchan/chatery_whatsapp.git
cd chatery_whatsapp

# Create environment file
cp .env.example .env

# Build and run with Docker Compose
docker-compose up -d

# View logs
docker-compose logs -f

# Stop the container
docker-compose down
```

#### Docker Commands

| Command | Description |
|---------|-------------|
| `docker-compose up -d` | Start container in background |
| `docker-compose down` | Stop and remove container |
| `docker-compose logs -f` | View live logs |
| `docker-compose restart` | Restart container |
| `docker-compose build --no-cache` | Rebuild image |

#### Docker Volumes (Bind Mounts)

The following local host directories are bind-mounted and persisted across container restarts:

| Host Directory | Container Path | Description |
|----------------|----------------|-------------|
| `./sessions` | `/app/sessions` | WhatsApp authentication credentials (`creds.json`), config, and message cache (`store.json`) |
| `./public/media` | `/app/public/media` | Auto-saved received media files organized by `{sessionId}/{chatId}/` |

## ⚙️ Configuration

Create a `.env` file in the root directory:

```bash
PORT=3000
NODE_ENV=production
CORS_ORIGIN=*

# Dashboard Authentication
DASHBOARD_USERNAME=admin
DASHBOARD_PASSWORD=securepassword123

# API Key Authentication (leave empty or 'your_api_key_here' to disable)
API_KEY=your_secret_api_key_here

# Performance & Multi-Session Optimization
SYNC_FULL_HISTORY=false
AUTO_DOWNLOAD_MEDIA=true
MAX_MESSAGES_PER_CHAT=100
MAX_MEDIA_DOWNLOAD_SIZE_MB=25
```

### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `3000` | Port for Express HTTP & Socket.IO server |
| `NODE_ENV` | `development` | Environment mode (`development` or `production`) |
| `CORS_ORIGIN` | `*` | Allowed CORS origins for REST API and WebSocket |
| `DASHBOARD_USERNAME` | `admin` | Username for dashboard & web client login |
| `DASHBOARD_PASSWORD` | `admin` | Password for dashboard & web client login |
| `API_KEY` | *(empty)* | Secret key for `X-Api-Key` header authentication |
| `SYNC_FULL_HISTORY` | `false` | Sync full chat history on WhatsApp connection (heavy memory) |
| `AUTO_DOWNLOAD_MEDIA` | `true` | Automatically download and save incoming media to server |
| `MAX_MESSAGES_PER_CHAT` | `100` | Maximum message history kept in memory per chat |
| `MAX_MEDIA_DOWNLOAD_SIZE_MB` | `25` | Maximum media file size allowed for auto-download (in MB) |

## 🔐 API Key Authentication

All WhatsApp API endpoints are protected with API key authentication. Include the `X-Api-Key` header in your requests.

### How to Enable

1. Set a strong API key in your `.env` file:
```bash
API_KEY=your_super_secret_key_12345
```

2. Include the header in all API requests:
```bash
curl -X GET http://localhost:3000/api/whatsapp/sessions \
  -H "X-Api-Key: your_super_secret_key_12345"
```

### Disable Authentication

To disable API key authentication, leave `API_KEY` empty or set it to `your_api_key_here` in `.env`:

```bash
API_KEY=
# or
API_KEY=your_api_key_here
```

### Error Responses

| Status | Message | Description |
|--------|---------|-------------|
| 401 | Missing X-Api-Key header | API key not provided in request |
| 403 | Invalid API key | API key doesn't match |

## 🚀 Quick Start

1. **Start the server**
```bash
npm start
```

2. **Create a session**
```bash
curl -X POST http://localhost:3000/api/whatsapp/sessions/mysession/connect \
  -H "X-Api-Key: your_api_key" \
  -H "Content-Type: application/json"
```

3. **Get QR Code** - Open in browser or scan
```
http://localhost:3000/api/whatsapp/sessions/mysession/qr/image
```
> Note: QR image endpoint also requires API key. Use curl or include header.

4. **Send a message**
```bash
curl -X POST http://localhost:3000/api/whatsapp/chats/send-text \
  -H "X-Api-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"sessionId": "mysession", "chatId": "628123456789", "message": "Hello!"}'
```

## 💬 WhatsApp Web Client (`/wa-web`)

Chatery includes a built-in, lightweight web client interface that allows you to chat directly through your connected WhatsApp session:

- **URL:** `http://localhost:3000/wa-web`
- **Protection:** Protected by the same dashboard authentication (`dashboardAuthGuard`).
- **Features:** Real-time chat list, message thread viewer, instant message sending, media preview, and incoming message notifications via Socket.IO.

## 🧪 Testing

The backend includes a comprehensive test suite with 160+ automated tests across unit, integration, and WebSocket modules using the native Node.js test runner:

```bash
# Run all tests
npm test

# Run only unit tests (BaileysStore, MessageFormatter, Auth Middleware)
npm run test:unit

# Run only WebSocket tests (Rooms, Event Emitters, Broadcasts)
npm run test:websocket

# Run only REST API integration tests
npm run test:integration
```
