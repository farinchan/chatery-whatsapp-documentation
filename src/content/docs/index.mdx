## Key Capabilities

- 📱 **Multi-Session Support** - Manage multiple WhatsApp accounts simultaneously with independent authentication
- 🔌 **Real-time WebSocket** - Instant notifications for messages, status, reactions, calls, and group updates
- 👥 **Group Management** - Create groups, manage participants/admins, update settings, and preview invite links
- 📨 **Rich Messaging** - Text, image, video, audio (PTT/voice note), WebP sticker, location, contact, and poll messages
- 👍 **Reactions & Message Control** - React with emojis, pin messages, star messages, and revoke (delete for everyone)
- 🗂️ **Chat Organization** - Pin, archive, and mute chats with customizable durations
- 🏷️ **WhatsApp Business Labels** - Create, delete, and tag chats with business labels (20 color presets)
- 👤 **Contacts & Profile** - Add/save contacts, check registration, fetch business profiles, block contacts, and update bio/name
- ↩️ **Reply & Quoting** - Reply/quote specific messages via `replyTo` parameter
- 📤 **Bulk Messaging** - Send messages, images, and documents to multiple recipients with background jobs & tracking
- 📥 **Auto-Save Media** - Automatically stream and save incoming media files to server disk
- 💾 **Persistent Store** - High-speed in-memory message and contact store with disk synchronization
- 🔐 **Session Persistence** - Sessions survive server restarts without re-scanning QR codes
- 🎛️ **Admin Dashboard** - Web-based dashboard with real-time monitoring and interactive API tester
- 💬 **WhatsApp Web Client** - Lightweight built-in web chat interface at `/wa-web`
- 🧪 **160+ Automated Tests** - Comprehensive unit, WebSocket, and integration testing suite
- 📄 **Swagger UI** - Interactive API documentation at root URL (`/`)
